# Simple Interest Calculator

A simple, user-friendly tool written in Shell Scripting / Python / HTML to compute simple interest based on principal amount, annual interest rate, and time period in years.

---

## 📌 Formula

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
* **P** = Principal amount
* **R** = Annual interest rate (in percentage)
* **T** = Time period (in years)

---

## 🚀 Features

* Calculates simple interest accurately based on user inputs.
* Computes the total amount payable ($\text{Principal} + \text{Interest}$).
* Easy-to-use interface and clean execution.
